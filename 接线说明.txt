======================================================================
  SHADE 智能窗帘 — 硬件接线说明 (v3 全部板载资源版)
  普中A2开发板 (STC89C52) + 树莓派
======================================================================

【一、文件位置】
  C51固件:    shade\firmware\src\
  树莓派程序:  shade\host\

----------------------------------------
  I2C 总线 (3个设备共用)
----------------------------------------
  P2.0(SCL) ──┬── BME280 SCL (地址0x76)
              ├── BH1750 SCL (地址0x23)
              └── PCF8591 SCL (地址0x48)
  P2.1(SDA) ──┼── 同上(三设备SDA并一起)
  VCC 5V ─────┼── 三模块 VCC  (面包板上共用一行)
  GND ────────┴── 三模块 GND

----------------------------------------
  HC-SR04 超声波
----------------------------------------
  P3.6 ── TRIG
  P3.2 ── ECHO   (占用INT0, K1按键作废)
  5V   ── VCC
  GND  ── GND

----------------------------------------
  步进电机 28BYJ-48 + ULN2003
  接P1高4位, 板载高4LED会随电机闪烁(演示效果拉满!)
----------------------------------------
  P1.4 ── IN1       高4LED实时显示步进状态!
  P1.5 ── IN2       (D1~D4会跟着电机转动闪烁)
  P1.6 ── IN3
  P1.7 ── IN4
  5V   ── VCC(ULN2003)
  GND  ── GND

  ULN2003输出 → 28BYJ-48五线插头(唯一方向)

====================================
  ✅ 不拔任何跳线帽! 不接任何外置LED!
  J24保持不动 → 8个LED全部板载工作:
  P1.0~P1.3 → D5~D8 状态灯(绿/红/黄/备用)
  P1.4~P1.7 → D1~D4 电机步进可视化
====================================

----------------------------------------
  板载资源 (全部利用, 零外接)
----------------------------------------
  8-LED模块(J24插着):
    P1.0=D5(绿) LED_RUN   500ms闪烁 运行指示
    P1.1=D6(红) LED_ALARM 报警常亮
    P1.2=D7(黄) LED_MOTOR 电机动作亮
    P1.3=D8     备用
    P1.4~P1.7   D1~D4 步进电机驱动 + LED步进可视化

  LCD1602:  P0全口数据, P2.5=RS, P2.6=RW, P2.7=E
  蜂鸣器:   P2.3
  按键K2:   P3.3 MODE 切换LCD页面
  按键K3:   P3.4 UP   增加光照阈值
  按键K4:   P3.5 DOWN 减小光照阈值
  按键K1:   P3.2 作废(被HC-SR04 ECHO占用)

----------------------------------------
  C51 <-> 树莓派 (一根USB线搞定)
----------------------------------------
  A2板USB口 → Pi USB口
  设备路径: /dev/ttyUSB0 (CH340)

  或者杜邦线:
  P3.0 RXD <-- Pi TXD(14)
  P3.1 TXD --> Pi RXD(15)
  GND ------ Pi GND

====================================
  引脚占用总览
====================================
  P0 全口  → LCD1602 数据总线
  P1.0~P1.3 → LED 状态指示灯(板载)
  P1.4~P1.7 → 28BYJ-48步进电机(IN1~IN4)
  P2.0~P2.1 → I2C总线(SCL/SDA)
  P2.3     → 蜂鸣器
  P2.5~P2.7 → LCD1602(RS/RW/EN)
  P3.0~P3.1 → UART串口
  P3.2     → HC-SR04 ECHO (K1作废)
  P3.3     → K2 MODE按键
  P3.4     → K3 UP按键
  P3.5     → K4 DOWN按键
  P3.6     → HC-SR04 TRIG

  空闲: P2.2, P2.4, P3.7 (3脚备用)
